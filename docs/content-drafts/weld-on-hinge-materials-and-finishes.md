# Specifying Hinge Materials and Finishes in an Inquiry

Identify the required material and surface condition explicitly. A product photograph does not establish either, and a description used for the body may not describe the pin or other components.

## Separate the components

Use the product drawing to identify which component each requirement applies to. If the body and pin have separate requirements, state them separately. Do not assume that every component uses the same material because the hinge is sold as one assembly.

If you are working from a customer drawing, retain its exact requirement and revision. Mark questions that still need confirmation instead of replacing the requirement with a generic label.

## Describe the environment and fabrication process

Tell the supplier where the assembly will be used and what processing is planned after the hinge is received. Treat any proposed finish as a point to review against the actual fabrication requirements.

Do not infer outdoor suitability or corrosion performance from a bright or dark surface in a photograph. A useful answer needs a defined product and specification.

## Ask how the requirement is confirmed

If documentation is required, specify what needs to be supplied with the order and which product it must cover. Do not assume a document is included unless the quotation states it.

Keep the agreed material and finish description with the drawing revision and quotation. Later changes should identify the affected components.

## Inquiry checklist

- Exact product family and size.
- Component-specific material requirements, if defined.
- Required surface condition or finish.
- Application environment and subsequent processing.
- Any required supporting documentation.
- Open questions needing confirmation.
