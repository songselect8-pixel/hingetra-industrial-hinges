# Flag Hinge Handing and Removal: What to Show on the Drawing

A left or right description is incomplete unless both parties use the same viewing direction. Send a view of the actual door and frame, and mark the opening direction before discussing a flag hinge.

## Establish the viewing direction

Label the side from which the drawing is viewed. Identify the fixed frame, moving door and hinge location. A simple arrow showing the opening direction is clearer than a written “left-hand” note without a view.

If a project contains mirrored doors, show both arrangements. Do not assume that turning one photograph over defines a second available product.

## Identify the exact structure

HINGETRA’s flag family contains two separately recorded structures. Keep each product image with its matching dimension table. The current catalog does not name them as left and right versions, so a buyer should reference the actual image and size entry.

Mark the feature that distinguishes the required part. This prevents a quotation from using the dimensions of one structure with the photograph of the other.

## Explain the removal requirement

State whether the door needs to detach and show the intended path. Ask the supplier to confirm that the selected construction permits that movement. Include any top cover or surrounding frame that restricts access.

A hinge name alone does not establish the space needed for removal. Keep the disengagement geometry and handling space visible in the installation view.

## Inquiry checklist

- Door view with its viewing direction labeled.
- Fixed and moving parts identified.
- Opening direction and any removal requirement.
- Matching product image and exact dimension entry.
- Quantity, destination and drawing revision.
