# Adjustable Weld-On Hinges: Specify the Movement You Need

An adjustable hinge inquiry should say what needs to move and why. “Adjustable” alone does not tell a supplier whether you need to change a door gap, compensate for an installation position or allow later service adjustment.

## Mark the required movement

Start with the closed door and fixed frame. Draw an arrow showing the required movement and identify the feature that must change position. Give the desired positions as drawing dimensions, with units. If only one direction may change, mark the others as fixed.

Do not assume that adjustment in one direction provides adjustment in every direction. The mechanism and available movement need to be checked against the exact product drawing.

## Show the installed access

An adjustment feature needs access in the assembled door. Show nearby panels, frame returns and other parts that might restrict the operation. Explain whether adjustment is required during assembly only or while the door remains installed.

Ask how the selected arrangement is secured after adjustment. Keep this as a product-specific question rather than copying instructions from a visually similar hinge.

## Keep the reference and requested change together

HINGETRA lists an adjustable hinge family and customization support. Reference the listed size, then attach the required movement drawing. A request to change the available movement is a separate requirement for review; it is not established by the family name.

Include the hinge quantity, door arrangement and current drawing revision. If the purpose is to solve a gap problem, show the gap at the relevant locations instead of supplying only an overall door photograph.

## Before requesting a quotation

- Identify the exact hinge reference.
- Mark the required movement and fixed dimensions.
- Show access in the assembled position.
- Ask about securing the final position.
- Keep the agreed drawing revision with the quotation.
